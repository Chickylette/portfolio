The Element Road

The Element Road is a third-person RPG that sets in a world possessed with magic. The player's gifted talent grants the power to retrieve elements from surrounding objects, thus create objects or spells to solve daily requests or fight against monsters. The player embarks on their own journey.

Core Mechanics

Grab Element System

Mechanic Overview

The Grab Element System is a core gameplay mechanic that allows players to extract elemental properties from naturally occurring objects in the environment. These elements serve as the foundation for spell crafting and certain item crafting interactions.

Players can hold up to two active elements, one in each hand. By acquiring different elements from their surroundings, players can experiment with elemental combinations to create spells and overcome challenges during exploration, puzzle-solving, and combat.

Element Sources

Each element is associated with specific environmental sources. Players must identify and interact with these sources to acquire the elements required for crafting.

Element Example Sources
Earth Stones, Natural Pathways
Water Ponds, Rivers, Lakes
Wind Wind Chimes, Strong Wind on Bridges
Wood Trees

To maintain consistency within the game's elemental system, only pure, naturally occurring materials can serve as elemental sources. For example, players can extract Wood from a living tree, but not from processed wooden planks or furniture.

Player Interaction

When the player hovers their cursor over a valid elemental source, the cursor changes into a pointing hand to indicate that the object is interactable.

Left-clicking acquires the element into the player's left hand, while right-clicking assigns it to the right hand. The corresponding HUD element slot updates immediately to display the newly acquired element.

Each hand can hold only one active element. Acquiring another element automatically replaces the previously held element, allowing players to adapt their elemental combinations without cooldown restrictions.

Design Rationale

The Grab Element System was designed to make environmental interaction a fundamental part of gameplay rather than a secondary activity. By requiring players to obtain elements from their surroundings, the system encourages exploration, environmental awareness, and strategic decision-making.

Limiting players to one element per hand introduces a deliberate constraint on resource management. Players must consider which elements to retain and when to replace them, particularly when preparing for combat or solving environmental puzzles.

Allowing elements to be replaced instantly prevents the system from becoming overly restrictive, supporting experimentation with different combinations. Together with clear visual feedback, these decisions aim to create an intuitive mechanic that connects exploration, spell crafting, and combat into a cohesive gameplay loop.
